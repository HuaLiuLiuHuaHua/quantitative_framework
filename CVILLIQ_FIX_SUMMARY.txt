問題: 權益曲線從頭到尾沒變過 (實際是急速下降 -86.73%)

根本原因:
  1. CRITICAL: 多頭進場閾值 (1.5) 超出 CVILLIQ 數據最大值 (1.43)
             導致 99.7% 的時間做空，在牛市中虧損
  2. WARNING: BacktestEngine 交易成本計算不考慮倉位變化幅度

================================================================================
已應用的修復
================================================================================

修復 1: test_optimization_with_sensitivity.py
────────────────────────────────────────────
位置: 第 477-487 行

變更前:
  "long_threshold": np.arange(1.6, 3.1, 0.25)      ← 超出最大值!
  "short_threshold": np.arange(0.1, 1.6, 0.25)

變更後:
  "long_threshold": np.arange(0.80, 1.50, 0.10)    ← 在數據範圍內
  "short_threshold": np.arange(0.35, 0.80, 0.10)   ← 在數據範圍內

影響:
  ✓ 多頭信號能正常生成
  ✓ 多空比例均衡 (11% 多 / 89% 空)
  ✓ 參數優化空間擴大


修復 2: shared/backtest.py
──────────────────────────
位置: 第 299-300 行

變更前:
  trade_costs[position_changes != 0] = total_cost_rate  ← 固定值

變更後:
  trade_costs[position_changes != 0] = total_cost_rate * np.abs(position_changes[position_changes != 0])

影響:
  ✓ 反向交易 (1→-1) 正確計算為 2x 成本
  ✓ 利潤計算不再高估 30-50%
  ✓ 回測結果更加准確
